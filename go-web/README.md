# Go Game (Web)

A single-file HTML/JavaScript implementation of the board game Go, playable in any modern web browser. Includes AI opponent, ko rule enforcement, and multiple board sizes.

## Features

- **Full Go rules** -- capturing, ko rule, scoring
- **AI opponent** for single-player games
- **Multiple board sizes** (9x9, 13x13, 19x19)
- **Responsive UI** with clean CSS styling
- **No dependencies** -- runs entirely in the browser

## Usage

Open the HTML file in any web browser:

```bash
open go-game.html
```

Or double-click `go-game.html` in your file manager.
